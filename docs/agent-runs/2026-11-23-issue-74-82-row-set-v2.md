## Decisions and discoveries

- Order of rules: pilot status, then no-action, then lineups. 36 of the 1,039 no-action possessions were multiple-lineup before.
- The rule uses events only, not the possession's end reason or score. It found 1,039 accepted no-action possessions in 2022–23 (the #82 review's 996 counted only those starting within 24 s of a period end). All score 0.
- Excluding them removes about half the end-of-period coefficient (−30.5 to −15.9) and about 80% of the held-out time gain. A residual end-of-period effect remains and is unexplained (game-final possessions are a candidate, **Inferred**).
- The context-only comparator no longer beats zero-context player RAPM.
- ADR number 0018 was taken by #32, so this decision is ADR-0019.
