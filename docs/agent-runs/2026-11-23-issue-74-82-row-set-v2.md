## Maintainer decision

ADR-0019 is Accepted, option B: exclude only accepted possessions whose first event is `period_end`. Real run-outs, held balls and other outcome-free endings stay eligible. Eligibility never depends on later actions or outcomes, and the rule is not justified by RAPM versus the context-only comparator. Variants A (outcome-based `no_action`) and C (keep all) are versioned sensitivity alternatives.
