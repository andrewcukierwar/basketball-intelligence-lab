## Objective and scope

Pin, capture, build, check and record 2012–13 through 2015–16 from the default path (no ADR-0023 order repair), run `season_quality.py`, build canonical RAPM row sets for seasons that pass the ADR-0022 hard gates, and add the seasons to the eligibility matrix. Data only: no model fitted, no network, no 2025–26 or later files, nothing under `data/` committed. The procedure is that of the [#97 handoff](2026-11-24-issue-97-backfill-2004-08.md).
