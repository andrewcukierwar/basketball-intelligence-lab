# Machine-only evidence for V2-free NBA possessions

**Development audit for [#160](https://github.com/andrewcukierwar/basketball-intelligence-lab/issues/160), 2026-11-28.** Bill Mill's archive is a feasible V3 input and a separate lineup reconstruction. Bentes's newer CDN-derived event table is the most promising free lead for missing companion fields. Neither establishes an independently observed event-level lineup or possession reference. The audit leaves [#133](https://github.com/andrewcukierwar/basketball-intelligence-lab/issues/133) blocked.

We examined the already exposed Memphis at Portland game of 2023-11-03 (NBA `0022300007`, ESPN `401584095`). We inspected 2025–26 and 2026–27 coverage metadata only. This audit made no prospective game selections, ran no prospective scorer, and incurred no data spend.

## Ranked use and proposed registration for #133

1. **First choice for development.** Use archived V3 for primary events and Bentes's post-2025–26 CDN-derived fields as the first companion to qualify. Require authorship and byte provenance for each needed role and compare on already-exposed games. Use Bill stints and NBA Lineup Model segments as diagnostics. A shared league feed can supplement missing fields without providing independent corroboration for those fields.
2. **Targeted semantic evidence.** Match ESPN attempts, turnovers, substitutions and recoveries by game, period, clock, type, actor and within-clock ordinal. Cross-check rare official calls with scorer and officiating reports where available. Record duplicate, ambiguous, conflicting and unmatched events separately. Same clock and team alone are insufficient to resolve mixed free-throw/substitution sequences.
3. **Full reference still missing.** A new machine-only acceptance design needs a rights-cleared full-game stream with independently established event capture, event-level ten-player lineups and explicit or independently reconstructable possession ownership. BigDataBall is the strongest schema lead if its field provenance and possession semantics can be confirmed. Sportradar on-venue or independent video/tracking-derived annotations are alternatives if event provenance and rights can be demonstrated. Public NBA-derived reconstructions qualify as development comparators.

Before opening any eligible sample, pin the source bytes, collection lineage, offsets/rounding, input order, event taxonomy, ambiguity rules, coverage denominator, exact game selection and outcome access order. Freeze one conversion, one prediction digest and a separate scorer. Retain the hard reconciliation checks for game score, minutes, plus-minus, lineups, possession alternation and score allocation. Include the #138 negative control and require zero decisive ownership contradictions on accepted games. Count misses per event family, distinguish lineup age within same-clock sequences, and report scoring and scoreless possessions separately. Use #133's existing numerical coverage/fidelity/downstream limits as the starting specification where the metrics are comparable. Predeclare new numerical limits for independent matching, lineup mismatch exposure and targeted rare cases only after evidence availability is proven on development games. Conditional on qualifying that reference, submit the exact registration for independent review and maintainer approval before drawing or opening a prospective sample. Stop if the reference cannot demonstrate the required field coverage and lineage.

In Bentes, sum `pts_poss` by `team_poss` and `pts_team` by `team`. Compare each player to minutes and plus-minus in `data/raw/2023-24/issue-52-v1/player_game_logs.parquet`. Compare actor coverage by type and preserve ambiguous clocks in the report.

For the ownership comparison, use Bentes made (1), missed (2) and turnover (5) events. In ESPN classify turnover titles containing “turnover,” “traveling” or “offensive charge” first.
