# Historical NBA data-source audit

**Ledger revision:** 2026-11-23, revision 2. Scope is the 2022–23 NBA pilot and historical inputs for the 2026–27 EPM methodology. [Issue #2][issue]

**Pilot source-of-record candidate:** Use Shufinskiy's pinned 2022–23 NBA Stats V2 event CSVs for the regular season and playoffs. The files contain ordered event fields, stable NBA game IDs and explicit player IDs for both participants in every observed substitution. Keep original row order and provenance, and account for the observed duplicate events and terminal-score exceptions. Bentes event, possession and stint files serve as processed comparisons. This updates the earlier Bentes recommendation. [Decision records](DECISIONS.md) [Pinned archive][shuf-tree]

**Reconciliation:** Use NBA.com box scores as the authority for final scores, team totals, player minutes and plus-minus. Use Bill Mill's NBA-derived team and player game logs as the machine-readable comparison candidate and the pinned V3 archive's end-of-final-period scores as an event-feed check. Use `pbpstats` with the pinned V2 and shot-chart files for independent parsing. ESPN via hoopR remains a conditional alternate publisher pending permission and a crosswalk. These NBA-derived comparisons can isolate processing or feed errors while sharing upstream NBA data. Bentes does not identify its exact endpoint for the pilot season. ## Pilot acceptance and outstanding evidence

2022–23 is the most recent season in both documented SPM training windows. Its published files span several event feeds and include matching regular-season and playoff assets. This makes it a useful data-quality pilot. Treat 2022–23 as overlapping reference-model training when evaluating historical fidelity. It can serve as an independent BIL holdout only under a separate, earlier BIL model-fit cutoff. [EPM methodology](https://dunksandthrees.com/about/epm)

1. **Confirm usage and lineage.** Determine whether the intended internal research acquisition and any future publication are permitted for each exact feed and asset. Identify Bentes's upstream 2022–23 endpoints if possible. Use only permitted inputs in the pilot. Document alternatives if a candidate is blocked.
2. **Freeze input snapshots.** Record provider, URL and revision, upstream feed, season and type, retrieval time, earliest evidenced availability and later correction times, locally computed SHA-256, row count, schema, coverage, exclusions, refresh behavior, permitted use, attribution and redistribution limits. Current file timestamps are insufficient to establish historical availability. Keep input data outside Git.
3. **Specify normalization in issue #3.** Cover season-type and ID crosswalks, event order at identical clocks, scoring deltas, substitutions, and possession boundaries. Keep source and normalized values traceable, including unassigned points and source corrections. Track play-in classification and exclusions explicitly.
4. **Validate in issue #5.** Compare accepted games with the official game list and official final scores. Reconcile the player-minute budget, per-player minutes and plus-minus with documented tolerances for rounding. Extend the successful offline `pbpstats` check to a representative sample and record any events requiring starter or other overrides. On a stratified set of games, compare lineup changes, possessions and scores with that parser and an alternate event source where permitted. Include overtime, same-clock substitutions, technical and retained-possession free throws, replay and end-period events. Record independent-source coverage and gaps in the exception report.
5. **Profile tracking separately.** The six-season audit measured matchup identities and exposure, season-total hustle and rim coverage, and the limits of historical availability. Use the proposed retrospective matchup cohort and report zero opportunities and missing rows separately. The exact EPM feature set and access to underlying trajectories remain open. [Public tracking audit](research/nba-defensive-tracking-audit.md) [EPM uncertainty register](research/epm-uncertainties.md)

The audit establishes a preferred source and workable comparison paths, with measured exceptions. Pilot acceptance still requires permitted use for the intended scope, a box-score source for the full season, stable ID and as-of contracts, and reconciliation. [Issue #3][contracts] [Issue #5][pilot]
